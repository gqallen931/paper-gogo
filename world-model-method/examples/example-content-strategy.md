# 示例：同一个任务，两种产出方式

**任务**：帮我策划一条关于「DeepSeek」的短视频选题。

---

## ❌ 默认方式（一个 token 接一个 token 顺嘴生成）

> "DeepSeek 是一款国产大模型，它性能强大、开源免费，下面我们来盘点它的五大亮点……"

流畅、能用，但：没问过目标是什么、没比过别的角度、跟全网同质化、完播率大概率扑街。**它是"生成"出来的，不是"想"出来的。**

---

## ✅ 世界模型工作法

```
【目标 & 成本】
  目标：完播率高 + 引发转发（不是讲全、是讲爽）
  要最小化：同质化、前 3 秒劝退、非技术受众听不懂
  硬约束：去 AI 化表达；可以有钩子但不能标题党到失实

【世界模型】
  受众：普通人——对 AI 既焦虑又好奇，但听不懂参数
  平台：完播率为王，前 3 秒定生死
  竞品：几乎都在比"技术参数多强" → 红海、同质
  动态：信息差越大，人越想点；越"跟我有关"越想转

【候选路径 & 后果预测】
  方案 A「盘点它多强大」→ 同质化、参数劝退普通人、完播低
  方案 B「DeepSeek 让谁失业」→ 有焦虑钩子，但已被做烂、审美疲劳
  方案 C「你免费用的 DeepSeek，背后是一场别人没料到的'阳谋'」
        → 信息差 + 悬念 + 不站队，完播潜力高；风险：叙事别夸大失实

【选择】
  选 C。它最大化"信息差悬念"（动态里最强的拉力），且天然绕开
  参数劝退、踩中"去 AI 化/不失实"两条硬约束。

──────── 以下是渲染出的成品 ────────
开头脚本（前 3 秒）：
  "你每天免费薅的 DeepSeek，可能是这几年最被低估的一步棋——
   它真正改变的，不是你写作业的速度，而是整个游戏的规则。"
（后续分 3 段：它免费开源动了谁的奶酪 / 为什么对手难受 / 跟你有啥关系）

【自检】
  完播钩子？✅ 前 3 秒有悬念  同质化？✅ 避开了参数红海
  失实？✅ 用"可能/被低估"留余地，不下绝对断言  去 AI 化？✅
```

---

**差在哪**：默认方式给了"一个能用的答案"；世界模型工作法给了"一个**比较过 3 条路、对着目标选出来、并自检过**的答案"。任务越重要，这个差距越值钱。
